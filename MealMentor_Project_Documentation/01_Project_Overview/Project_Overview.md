## Abstract

MealMentor (NutriSense AI) is a full-stack, AI-assisted personalized nutrition tracking and meal planning web application built using Next.js 16, React 19, TypeScript, MongoDB, and a Python-based machine learning layer. The system is designed to address the gap between generic, one-size-fits-all dietary advice and the need for individualized, data-driven nutrition guidance.

The application implements a multi-tier architecture: a Next.js frontend with server-side rendering handles user interaction; a set of Next.js API routes provide RESTful backend services; a MongoDB database with Mongoose ODM persists user profiles, food logs, meal plans, weight entries, and feedback; and an isolated Python ML layer running XGBoost and Random Forest models provides learning-to-rank food recommendations and 7-day weight change forecasting, with a FastAPI service as an optional persistent backend.

The core nutrition engine is fully implemented and calculates Basal Metabolic Rate (BMR) using the Mifflin–St Jeor equation, Total Daily Energy Expenditure (TDEE) by applying activity-level multipliers, and daily calorie targets adjusted for health goals. Personalized micro- and macronutrient targets are derived from these, with condition-aware adjustments for diabetes (reduced sugar limit) and hypertension (reduced sodium limit).

Meal recommendations are generated by a two-stage pipeline: a rule-based engine filters and scores foods from a local dataset of 384 verified food items against each user's current nutrient gaps, and then an XGBoost learning-to-rank model re-ranks the candidates. Food image analysis using the Google Gemini Vision API allows users to photograph meals for automated nutrient recognition. An AI nutrition assistant is powered by the Gemini language model, with a deterministic local fallback engine for offline scenarios.

Additional features include barcode scanning via the OpenFoodFacts API, water intake tracking, streak monitoring, proactive nudge notifications, voice-input meal logging, custom food creation with ingredient-level nutrition calculation, grocery list generation, recipe fetching, and a 7-day nutrition history dashboard with weight trend visualization using Recharts.

## Introduction

Poor dietary habits and nutritional deficiencies are major contributors to preventable chronic diseases globally. Most existing nutrition apps provide either generic advice or tracking-only features without intelligent personalization. MealMentor addresses this by combining physiological calculations, machine learning re-ranking, AI vision, and real-time gap analysis into a cohesive web application. The project is implemented as a production-quality Next.js application, deployable on Vercel, and is designed for extensibility. All nutrition values are sourced from a curated food dataset and are not fabricated by the ML models.

---

## Problem Statement

Individuals seeking to improve their diet face several concrete challenges:

1. **Generic dietary advice** — Most apps provide fixed meal plans that do not adapt to personal physiology, activity levels, food preferences, allergies, health conditions, or financial budgets.
2. **Manual effort** — Tracking every food item manually is time-consuming and error-prone; most users abandon food diaries within days.
3. **No real-time gap analysis** — Users do not know which specific nutrients they are still missing mid-day, making it impossible to make informed food choices for remaining meals.
4. **Budget blindness** — Healthy eating guidance rarely accounts for economic constraints, making recommendations impractical for many households.
5. **Poor food photo recognition** — Photographing a meal for nutrition analysis typically requires premium third-party services.

MealMentor solves these problems by computing personalized daily targets from the user's biometric profile, displaying real-time nutrient gaps, generating gap-optimized meal recommendations using ML, enabling photo-based food recognition with Google Gemini Vision, supporting barcode-based packaged food logging, and providing budget-constrained recommendations.

## Proposed System

The proposed MealMentor system provides:

- Personalized BMR/TDEE/calorie-target calculation using the Mifflin–St Jeor equation
- Real-time nutrient gap tracking across 10 nutrients (calories, protein, carbs, fat, fiber, sugar, sodium, calcium, iron, vitamin C)
- AI-powered meal recommendations via a two-stage pipeline: rule-based scoring + XGBoost re-ranking
- Food photo nutrition analysis via Google Gemini Vision API
- Barcode scanning with OpenFoodFacts API integration and offline cache fallback
- AI chatbot assistant (Gemini LLM + local deterministic fallback)
- Water intake tracking with weight-based targets and streak monitoring
- Custom food creation with ingredient-level nutrition auto-calculation
- 7-day weight forecasting using a Random Forest model (via FastAPI)
- Grocery list auto-generation from recommended meal plans
- Voice-input meal logging using the Web Speech API

## Objectives

1. To implement a mathematically accurate BMR/TDEE/calorie pipeline using the Mifflin–St Jeor equation.
2. To develop a two-stage meal recommendation engine combining rule-based gap analysis with XGBoost learning-to-rank.
3. To integrate Google Gemini Vision for automated food photo nutrition analysis.
4. To enable barcode-based packaged food nutrition lookup via OpenFoodFacts.
5. To build a personalized AI nutrition chatbot with a deterministic offline fallback.
6. To track user weight trends and generate a 7-day weight change forecast using Random Forest regression.
7. To provide a complete food logging system with real-time nutrient gap visualization.
8. To implement a streak and habit tracking system to encourage consistent usage.
9. To design an accessible, responsive web interface following WCAG 2.1 AA guidelines.
